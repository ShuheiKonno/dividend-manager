# dividend-manager-gui

個人向け配当・ポートフォリオ管理アプリ（PySide6 / Qt6 ネイティブ GUI）。
株式・ETF・日本の投資信託（ISIN コード対応）を一括管理し、配当収入・取り崩し収入・損益をリアルタイムで可視化します。

## セットアップ

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe app.py
```

または `run.bat` をダブルクリックで起動。

## キーボードショートカット

`F1` でアプリ内に一覧を表示できます。すべて修飾キー付きなので、表の上で銘柄コードを
打っても誤爆しません。`Tab` キーだけでツールバー・絞り込み・表を辿れます。

| キー | 操作 |
|------|------|
| `F5` | 株価・配当・基準価額を取得（yfinance / ToushinReader） |
| `Ctrl` + `U` | USDJPY レートを取得 |
| `Ctrl` + `R` | データを再読込（ローカル CSV） |
| `Ctrl` + `N` | 新規銘柄を登録 |
| `Ctrl` + `E` | 選択行を編集（ダブルクリック / `Enter` でも可） |
| `Ctrl` + `D` | 選択行を削除（表の上では `Delete` でも可） |
| `Ctrl` + `M` | 税引前 / 税引後 モード切替 |
| `Ctrl` + `I` | 収入モード切替: 配当 → 定額取崩 → 定率取崩 → 配当 |
| `Ctrl` + `Shift` + `I` | 無効銘柄の表示切替 |
| `Ctrl` + `1` 〜 `4` | タブ切替（評価額 / 配当金 / 株価関連 / 配当関連） |
| `Ctrl` + `F` | 絞り込みボックスへ移動 |
| `Esc` | 絞り込みをクリア |
| `F1` | ショートカット一覧 |
| `Ctrl` + `Q` | 終了 |

列のソートはヘッダークリック、税引・収入モードの切替はツールバーの
ドロップダウンからも行えます（現在のモードは常にそこに表示されます）。

## 無効銘柄の扱い

編集ダイアログで「有効」を外した銘柄は、集計・構成グラフ・株価取得の対象から
外れます。表示メニューの **「無効銘柄も表示」**（`Ctrl` + `Shift` + `I`）を有効に
すると、表にだけ淡色で並ぶので再編集・復帰できます。

## データ取得

- **株式・ETF**: `yfinance` で株価・配当を取得（API キー不要）
- **日本の投資信託（ISIN コード）**: `ToushinReader` で基準価額を取得
  - `asset_type=fund` かつシンボルが ISIN 形式（例: `JP90C000J569`）の場合に自動で使用
- **USDJPY**: `yfinance`（`USDJPY=X`）で取得

## 投資信託の口数入力

日本の投資信託の基準価額は **1万口あたり** で表示されます。  
`保有株数` フィールドには **口数 ÷ 10,000** を入力してください。

```
例: 2,067,284口 保有 → 保有株数 = 206.7284
    基準価額が 39,764円/万口 → 取得単価 = 39764
```

## 取り崩しモード（Ctrl + I）

`Ctrl` + `I`（またはツールバーの「収入」ドロップダウン）で収入の算出方法を
切り替えられます：

| モード | 表示ラベル | 算出方法 |
|--------|-----------|---------|
| 通常 | 年間配当(円) | yfinance 取得配当 / 手動 override |
| 定額取崩 | 年間収入(円) | `withdrawal_fixed_jpy`（設定値）をファンドに適用 |
| 定率取崩 | 年間収入(円) | `時価評価額 × withdrawal_rate` をファンドに適用 |

株式・ETF は取り崩しモードでも配当をそのまま表示します。

## データファイル

| ファイル | 内容 |
|---------|------|
| `data/holdings.csv` | 銘柄マスタ（手動入力） |
| `data/market_data.csv` | 株価・配当キャッシュ（`F5` で更新） |
| `data/fx.csv` | USDJPY 履歴（最終行が最新レート） |
| `data/backup/` | 書込み前の自動バックアップ |

`data/` ディレクトリは `.gitignore` 済み（ローカル専用）。
